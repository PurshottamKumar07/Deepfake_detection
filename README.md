## Quick Start (Local / VS Code)

```bash
# 1. Clone and enter the project
cd final_year_projet

# 2. Install dependencies (requires uv)
uv sync --dev

# 3. Set your dataset root
#    Windows PowerShell:
$env:DATA_ROOT = "C:\path\to\your\dataset"
#    Linux/macOS:
export DATA_ROOT=/path/to/your/dataset

# 4. Inspect the dataset (run from Google Colab if dataset is cloud-only)
python -m src.data.inspect_dataset

# 5. Build the manifest (after confirming class names from inspection)
python -m src.data.build_manifest \
    --real-classes original \
    --fake-classes DeepFakes FaceSwap Face2Face FaceShifter NeuralTextures

# 6. Build leakage-safe splits
python -m src.data.build_splits

# 7. Validate the manifest
python -m src.data.validate_dataset

# 8. Run the test suite
uv run pytest tests/ -v
```

## Key Design Decisions

- **DATA_ROOT**: Set via environment variable or `configs/config.yaml`. Never hardcoded.
- **No data leakage**: Splits happen at source-video level, not per-frame.
- **No metadata invention**: Fields that cannot be determined are left empty with a report.
- **Modular**: Each modality (image/video/audio) is independent and testable on its own.
